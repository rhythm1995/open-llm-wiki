每节解决一件事。已经会开库的人从这里查；第一次用请先走 [教程](./tutorial.zh.md)。

## 打开或换一座 Vault

1. `⌘O`，或点列表栏文件夹加号，或 `⌘K` →「打开 Vault」。
2. 选本机 Markdown 文件夹。
3. 最近打开过的库会出现在欢迎台，点一下即可。

桌面端支持把文件夹拖到欢迎台。浏览器预览用的是内存演示库，不能换成你磁盘上的目录。

## 新建一篇笔记

1. `⌘N`，或点列表栏 `+`。
2. 列表里会出现标题输入框，改名后回车。
3. 在正文里写。默认所见即所得；点编辑器右上角 `</>` 切到源码。

应用会自动保存。状态栏显示当前文件路径。

## 用 wikilink 连两篇笔记

在源码或所见即所得里输入：

```md
详见 [[另一篇的标题]]
```

输入 `[[` 时会补全已有标题。点链接跳转；右侧「反链」显示谁链到当前篇。

frontmatter 里也可以写关系，例如：

```yaml
related_to: "[[Index]]"
contradicts: "[[Zettelkasten]]"
```

图谱两边都会画出来。断链会在 Inspector 里出黄条。

## 切编辑模式、查找、并排阅读

| 你想 | 怎么做 |
| --- | --- |
| 源码 | 点 `</>`，或 `⌘K` → 切换到源码 |
| 所见即所得 | 再点一次，或 `⌘K` → 切换到所见即所得 |
| 当前笔记里找 | `⌘F` |
| 整库搜索 | `⌘⇧F` |
| 按标题快开 | `⌘P` |
| 源码和阅读并排 | `⌘K` → 开启并排阅读预览 |

`⌘F` 只影响当前这篇，不会改你的默认编辑模式。

## 插入图片

粘贴、拖入，或用格式条的图片按钮。文件会落到 vault 的 `attachments/`（默认按笔记分子目录），正文写入相对路径，不是 data URL。

清理没人引用的附件：`⌘K` → 搜索「孤儿」或「清理」。

## 用命令面板

`⌘K` 打开命令列表。输入关键词过滤。常用：打开 Vault、设置、接入外部 Agent 记忆、查询 Vault、问题反馈。

![命令面板](./images/palette-zh.png)

`⌘P` 只快开文件，`⌘⇧F` 只搜正文，不要和 `⌘K` 混用。

## 看图谱并跳到笔记

1. 顶栏点「图谱」。
2. 拖动画布平移，滚轮缩放，点节点打开底部卡片。
3. 「过滤」按类型 / 标签收窄；「更多」里有布局（力导向 / 类型分层 / 时间轴）。
4. 点卡片或节点进入该笔记。

画布（`.canvas`）是孤立白板，不进图谱，也不出现在「新建」里。已有的 `.canvas` 仍可打开编辑。

## 读懂库健康并决定下一步

1. 顶栏点心跳图标。
2. 先看六格分数和「下一步」那一行。
3. 左边 11 条按结构 / 证据 / 信任分组。点一条看明细（桌面端）。
4. 右上角输入自然语言，点「问 Agent」——不要自己写查询。

![库健康总览](./images/health-zh.png)

> [!NOTE]
> 浏览器预览不跑那 11 条 QQL，只显示图谱即时分数。桌面端进视图后会后台扫描并填角标。

饥饿名单里的主张：`Active` 建议至少 2 条入链，`Contested` 建议至少 3 条。数字不够的行会着色。

## 把一篇来源提炼进 Wiki

适用：一篇 `type: Source` 或还没分类的材料，你想让 Agent 按规程写成 Summary / Entity / Concept。

1. 打开那篇笔记。
2. 设置 → Agent 记忆：一键接入（装好 MCP 与 `wiki-ingest` skill）。桌面端才能做这一步。
3. `⌘K` →「提炼进 Wiki」，或用笔记上的提炼按钮。
4. 选一个已安装的 Agent，发送。

Agent 应按 starter 里的 wiki-ingest 做：新 Summary、回写 Source 为 `Digested`、给实体和主张建页、在 `index.md` 挂一行。不要让它改 Source 正文（Source 当作不可变原文）。

## 使用应用内 Agent

1. 顶栏右侧点 Agent 面板开关（机器人那一颗）。
2. 选一个本机已安装的配方（如 opencode、claude-code）。
3. 用 `@` 把当前或其它笔记加进上下文。
4. 发送。工具调用会折成卡片。权限分三档：逐次询问 / 宽松 / 高危仍门控。

![应用内 Agent 侧栏](./images/agent-zh.png)

浏览器 mock 探测不到本机 Agent，侧栏会提示先安装。写过库的回合结束时，若存在 `hot.md`，应用会提醒你整页覆写会话缓存（不会自动改）。

「查询 Vault」会预填一条自然语言短指令，让 Agent 去跑健康或临时问题，而不是打开查询编辑器。

## 给外部 Agent 接上这座库

桌面端：设置 → Agent 记忆 → 一键接入。它会探测 Cursor / Claude Code 等，写入用户级 MCP 配置，必要时从 wiki-starter 播种 vault。

命令行等价物：

```bash
# 在 vault 根目录
npx --yes --package=github:rhythm1995/open-llm-wiki#path:packages/open-llm-wiki-skills \
  open-llm-wiki-skills install . --hooks
```

Agent 读库时的省 token 顺序：`hot.md` → `index.md` → 再按需 `read_note` / `links`。不要一上来全文检索。

## 改语言、主题、默认编辑模式

`⌘,` 打开设置。主题深 / 浅、界面简体中文 / English、默认 source / wysiwyg、附件布局都在这里。全部只存在本机。

状态栏右下角的 `EN` / `中` 也可以立刻切界面语言。

## 反馈一个问题

`⌘K` →「问题反馈」，或帮助手册里的反馈卡片，或设置 → 诊断。会打开 [GitHub Issues](https://github.com/rhythm1995/open-llm-wiki/issues)。桌面端请先在设置里导出诊断日志再贴。
