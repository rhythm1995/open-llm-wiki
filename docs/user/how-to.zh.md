## 打开或切换 Vault

1. 按 `⌘O`，或列表头上的文件夹加号，或 `⌘K` → **打开 Vault**。
2. 选磁盘上的一个 Markdown 文件夹。
3. 欢迎屏会列出最近打开过的库——点其中一个。

桌面端可以把文件夹拖到欢迎屏。浏览器预览用的是内存演示库，不能打开磁盘上的文件夹。

## 新建笔记

1. 按 `⌘N`，或列表头上的 `+`。
2. 出现行内标题框。改名后回车。
3. 在正文里写。默认是所见即所得；`</>` 切到源码。

应用会自动保存。状态栏显示当前路径。

## 用 wikilink 连两篇笔记

源码或所见即所得里写：

```md
See [[另一篇的标题]]
```

`[[` 会弹出标题补全。点链接即可跳转。右侧 **反链** 列出谁指向这里。

关系也可以写在 frontmatter：

```yaml
related_to: "[[Index]]"
contradicts: "[[Zettelkasten]]"
```

两者都会上图谱。断链会在检查器里出黄色横幅。

## 切换编辑模式、查找、并排预览

| 你想 | 这样做 |
| --- | --- |
| 源码 | 点 `</>`，或 `⌘K` → 切到源码 |
| 所见即所得 | 再点一次，或 `⌘K` → 切到所见即所得 |
| 在这篇里找 | `⌘F` |
| 搜整座库 | `⌘⇧F` |
| 按标题快开 | `⌘P` |
| 源码旁阅读 | `⌘K` → 打开并排阅读预览 |

`⌘F` 不会改你的默认编辑模式。

## 插入图片

粘贴、拖入，或用格式栏的图片按钮。文件落在库里的 `attachments/`（默认按笔记分文件夹）。正文存相对路径，不是 data URL。

清掉没人引用的文件：`⌘K` 搜「orphan」或「清理」。

## 用命令面板

`⌘K` 打开命令列表。输入过滤。常用：打开 Vault、设置、用户文档、接入外部 Agent 记忆、提炼进 Wiki、查询 Vault、问题反馈。

![命令面板](./images/palette-zh.png)

`⌘P` 只按标题快开文件。`⌘⇧F` 只搜正文。不要和 `⌘K` 混用。

## 看图谱并跳到笔记

1. 点工具栏的 **图谱**。
2. 拖移、滚轮缩放、点节点看底部卡片。
3. **过滤** 按类型 / 标签缩小。**更多** 里是布局（力导向 / 类型分层 / 时间轴）。
4. 点卡片或节点打开那篇笔记。

`.canvas` 是独立白板，不上图谱，也没有「新建」按钮。已有的 `.canvas` 仍可打开编辑。

## 看库健康并选下一步

1. 点心跳图标。
2. 先看六格分数和「下一步」那一行。
3. 左侧十一条按结构 / 证据 / 信任分组。点开看明细（桌面端）。
4. 右上角用自然语言提问，点 **问 Agent**。不要手写查询。

![库健康总览](./images/health-zh.png)

> [!NOTE]
> 浏览器预览不跑那十一条 QQL 模板，仍显示图谱即时分数。桌面端会在后台扫查询并填徽章。

饥饿目标：`Active` 主张至少要 2 条入链，`Contested` 至少 3 条。不够的行会高亮。

## 把这座库当成 AI 记忆

文件夹才是记忆。聊天记录不是。让 Agent 接到你正在浏览的同一批文件上。

### 一键接到 Cursor / Claude Code 等（桌面）

1. `⌘,` → **Agent 记忆** → 一键接入。
2. 应用给探测到的 Agent 写用户级 MCP 配置，把 `wiki-ingest` skill 装进当前库；空文件夹还可以种 wiki-starter。

命令行等价（已发布到 npm；第二行从 GitHub 装最新源码）：

```bash
# 在 vault 根目录
npx --yes open-llm-wiki-skills install . --hooks

# 或者直接从本仓库装：
# npx --yes --package=github:rhythm1995/open-llm-wiki#path:packages/open-llm-wiki-skills \
#   open-llm-wiki-skills install . --hooks
```

之后 Agent 有八个工具：`list_notes`、`read_note`、`write_note`、`links`、`search_notes`、`run_qql`、`vault_info`、`lint_vault`。见 [参考](./reference.zh.md#mcp-工具)。

### 应用内侧栏

1. 打开 Agent 栏（右上角机器人）。
2. 选本机已装的配方（opencode、claude-code …）。
3. 用 `@` 附上当前笔记或其它笔记。
4. 发送。工具调用收成卡片。权限三档：每次问 / 宽松 / 高风险仍拦截。

![应用内 Agent 侧栏](./images/agent-zh.png)

浏览器预览探测不到本机 Agent，会提示先安装。

**查询 Vault**（`⌘K`）只预填一句自然语言指令。它不会打开查询编辑器。

### Agent 应该先读什么

省 token 顺序：`hot.md` → `index.md` → 再按需 `read_note` / `links`。不要一上来全文检索。

`hot.md` 是库根上一篇短缓存，整页覆写，不是日志。应用内 Agent 在写过库的回合结束时会请你改它，不会替你写。

一条值得留下的回答：写成新笔记。记忆这样才能变厚。

## 把一篇源提炼进 Wiki

当你有一篇 `type: Source`（或还没标类型的原材料），想让 Agent 从中写出 Summary / Entity / Concept。先接记忆（[上一节](#把这座库当成-ai-记忆)）。

1. 打开那篇笔记。
2. `⌘K` → **提炼进 Wiki**，或笔记上的提炼控件。
3. 选一个已装的 Agent，发送。

Agent 应遵循 wiki-ingest：新写一篇 Summary，把 Source 标成 `Digested`，创建 Entity / Concept，并在 `index.md` 加一行。不得改 Source 正文。

## 改语言、主题、默认编辑模式

`⌘,` 打开设置。深 / 浅色、简体中文 / English、默认源码 / 所见即所得、附件布局都在这里。全部只存在这台机器。

状态栏的 `EN` / `中` 会立刻切换界面语言。

## 反馈问题

Help → **Report Issue…**，或 `⌘K` → **问题反馈**，或帮助手册里的卡片，或设置 → 诊断。会打开 [GitHub Issues](https://github.com/rhythm1995/open-llm-wiki/issues)。桌面端请先在设置里导出诊断日志。
